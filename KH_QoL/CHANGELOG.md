# Changelog

## 0.1.0-beta

First public beta.

- Settings window in English and Spanish, one tab per game, presets per game.
- One-click install of the official LuaBackend `v1.9.1-hook` (downloaded and SHA-256 checked, not bundled).
- **Kingdom Hearts Final Mix:** EXP, munny orbs, optional shop sales, item drop chance (≤100 %), pickup radius / automatic pickup, infinite HP/MP, movement speed (Sora, party, gliding), jump height, max HP/MP, enemy HP (bosses included), instant dialogue box transitions, instant Gummi travel (Warp Drive for worlds already reached).
- **KH II Final Mix, Birth by Sleep, Re:Chain of Memories (beta):** EXP, currency, infinite HP (and MP in KH II).
- Optional KH1 save profiles (Main / Testing) to keep test saves apart from your playthrough.
- Fails closed on unknown game versions; everything is reverted at 1x; saves and game files are never modified.
