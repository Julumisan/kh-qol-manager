# KH QoL Manager

Grind-reducer and quality-of-life mod manager for **KINGDOM HEARTS HD 1.5+2.5 ReMIX (Steam)**, running on LuaBackend.

- User documentation: [`KH_QoL/README.md`](KH_QoL/README.md)
- Project state and handoff: [`KH_QoL/docs/HANDOFF.md`](KH_QoL/docs/HANDOFF.md)
- Technical design and memory map: [`KH_QoL/docs/TECHNICAL.md`](KH_QoL/docs/TECHNICAL.md)
- Release: `powershell -ExecutionPolicy Bypass -File KH_QoL/tools/Build-Release.ps1`

The repository mirrors the game folder layout (the manager scripts sit next to the game executables). Everything else in the game folder is ignored by `.gitignore`.
